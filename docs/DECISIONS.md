# Decisions

| ID | Decision | Alternatives considered | Rationale |
|---|---|---|---|
| D-01 | **React 19 + TypeScript + Vite 8 + react-router 7**, plain CSS design tokens, no UI kit. | Svelte, Preact; Tailwind; component libraries. | Matches the brief's default stack; lean bundle; full control of the cosy look and accessibility. |
| D-02 | Pin dependency versions published ≥ 2 weeks before the build (e.g. vite 8.3.7, vitest 5.1.0, typescript 6.0.3). `.npmrc legacy-peer-deps` because npm 10.9's peer resolver crashed on vite-plugin-pwa's optional peers. | Latest-everything; TypeScript 7 native. | Supply-chain caution; typescript-eslint supports TS < 6.1. |
| D-03 | Ruleset **vanilla 1.6.15**, no mod support. | Attempt "mod-friendly" data. | Only vanilla can be verified. |
| D-04 | **Wiki raw-wikitext snapshot** as the main source for schedules, fish rules, shop hours and TV; stardew-valley-data (MIT) for item/gift/crop/bundle base data. | Game file extraction (not available, not redistributable); scraping HTML at runtime; the unlicensed `stardew-data` repo. | Lawful, attributable, semi-structured; never hit the wiki at runtime. robots.txt honoured (no crawling; ClaudeBot disallow respected by not crawling); polite one-off fetch. |
| D-05 | Fish rules **hand-curated as conjunctions** from wiki infobox + intro text rather than auto-parsed. | Parse infobox fields generically. | Infobox fields are flattened ("River • Secret Woods", "Spring • Fall / Secret Woods: …"); a generic parser would recreate the Cartesian-product bug the brief forbids. 77 entries are manageable and reviewable. |
| D-06 | Schedules **auto-parsed** from wiki tables with a typed label grammar; unparseable labels become `unknown` conditions. | Hand-transcribe 600 blocks. | Reproducible on wiki updates; honesty preserved for anything not understood. |
| D-07 | **Three-valued logic** everywhere; no probabilities. | Probabilistic "most likely" ranking. | The brief: never fabricate certainty or arbitrary probabilities. |
| D-08 | Time stored as minutes from 0:00 of the game day (to 26:00). | Game `hhmm` integers; real Date objects. | Simple arithmetic, natural after-midnight handling. |
| D-09 | **Next day** sets weather from fixed rules → user's TV forecast → *unknown*; time resets to 6 AM if used. | Carry yesterday's weather; ask in a modal. | No guessing, no interruption; the user can tap weather in one touch. |
| D-10 | Global **preview** (date/weather/time) kept in memory only and visibly badged; Today always shows the played day; "Make this my current day" commits. | Per-page previews. | Brief: previews must never mutate the saved day. |
| D-11 | **Save import** implemented (local XML parse); **SMAPI live bridge not built**. | Build a SMAPI mod + local HTTP bridge. | Save import is testable here with a synthetic fixture and works on PC/Mac/Linux with zero install. A SMAPI bridge needs a game install + C# build + live testing, none available → would ship an unverified integration. Technical design in IMPLEMENTATION_PLAN §6. |
| D-12 | **IndexedDB** (tiny wrapper) for profiles; localStorage fallback; `navigator.storage.persist()` requested. Writes happen right after each change. | idb library; debounced writes. | Debounced writes lost changes on quick reloads (found in browser testing). |
| D-13 | **Original art only**: pixel-art SVG nav icons, tinted pixel fish glyphs (5 shapes), monogram portraits, hand-drawn schematic map, generated PNG app icons. | Wiki/game sprites. | Licensing (game art is not redistributable). |
| D-14 | Map is a **schematic SVG** with region/building anchors, pixel-sized markers, pan/zoom, and a list alternative. | Tile-accurate game map; Leaflet. | Game maps can't be redistributed; tile paths aren't knowable from data; no heavy library needed. |
| D-15 | Calendar grid hides "minor" repeating info (Livin' Off The Land, reruns); clinic and planting layers off by default (toggleable). | Show everything. | First browser review showed the grid too busy; "do not present an enormous list". |
| D-16 | `BrowserRouter` + Workbox `navigateFallback`; base path configurable via `BASE_PATH`. | HashRouter. | Clean URLs; deep links work offline via the service worker. |
| D-17 | Service worker `registerType: 'prompt'`: users see "A new version is ready — Update / Later". | Auto-update. | Never swaps code under an open session; data schema is migrated on load by `sanitizeProfile`. |
| D-18 | Remixed bundles: user ticks which bundles they have. | Predict from save seed. | The random selection isn't derivable without the save's bundle data. |
| D-19 | Gift tastes shown as the villager's personal lists plus collapsible universal lists with an "overrides" note. | Fully resolve every item against categories. | Category membership (e.g. "All Artisan Goods (except …)") needs an item taxonomy the dataset doesn't provide reliably. |
| D-20 | E2E tests use the system Google Chrome (`channel: 'chrome'`). | Download Playwright's Chromium. | The cached Playwright browser didn't match 1.65; avoids a large download. `PW_CHANNEL=chromium` switches. |
